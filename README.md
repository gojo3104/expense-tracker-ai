🔥 Expense Tracker AI

Full Stack AI-powered expense tracking system with receipt OCR.

🚀 Tech Stack

Frontend

React (Vite)

Tailwind CSS

Recharts

React Router

Axios

Backend

Flask

SQLAlchemy

SQLite

OCR (Tesseract)

📦 Setup Instructions
1️⃣ Clone Repository
git clone https://github.com/gojo3104/expense-tracker-ai.git
cd expense-tracker-ai

🖥 Backend Setup
cd backend
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt
python app.py


Backend runs on:

http://127.0.0.1:5000

💻 Frontend Setup

Open new terminal:

cd frontend
npm install
npm run dev


Frontend runs on:

http://localhost:5173
